## Descrição
Criar uma baseline intermediária, **BL-PROJ**, entre BL-REQ e BL-IMPL, contendo apenas os documentos técnicos:
- DGD-ARQ-001: Documento de Arquitetura (v0.4 → v1.0)
- DGD-BD-001: Modelo de Dados (v0.4 → v1.0)
- DGD-TST-001: Plano de Testes (v0.2 → v1.0)

A BL-IMPL passa a conter DGD-COD-001/002 e as versões vigentes desses três documentos.

## Justificativa
O código ainda não existe, então os critérios da BL-IMPL não podem ser cumpridos. Congelar os documentos técnicos agora dá à equipe uma referência estável para começar a implementação.
