## Descrição
Seguir os templates da disciplina. A antiga ERS (DGD-REQ-001) vira o Documento de Requisitos, com Introdução, Definições, Visão Geral e tabelas de RF, RNF e RN com as colunas ID, Descrição, Prioridade e Depende de; os critérios de aceitação passam para a descrição de cada RF. Cria-se uma nova ERS (DGD-REQ-003), com arquitetura, casos de uso, diagrama de classes, modelo lógico, regras de validação, interfaces e API REST, e um Plano de Projeto (DGD-GER-006).

## Justificativa
Os templates são o formato exigido para a entrega acadêmica.
